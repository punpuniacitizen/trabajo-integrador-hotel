# Diseño

Material de diseño del proyecto. No lo usa la app directamente.

- `identidad/`: brandbook del hotel ficticio (logo en sus versiones, paleta, tipografías, tono).
- `stitch/`: pantallas generadas en Google Stitch y el prompt usado para generarlas.

Los archivos finales que sí usa la web (logos SVG, favicon) se copian a `app/static/brand/`.
